# Skyhop by Parker Data Link

One-touch sky hopping game. Tap to hop, fly through the gaps, dodge the towers.

- Web: https://skyhop-c3n.pages.dev
- Android package: `link.parkerdata.skyhop`
- All art and sound are drawn/synthesised in code (`index.html`). No third-party assets.

## Layout

- `index.html` — the whole game (canvas + WebAudio)
- `manifest.json`, `serviceworker.js` — PWA bits for the web version
- `privacy.html` — privacy policy
- `icons/` — generated by `make_icons.py` (Pillow)
- `android-app/` — Capacitor shell with native AdMob (banner, interstitial every 3rd game over, app open)

## Build the Android bundle

```powershell
cd android-app
npm install
Copy-Item ..\index.html,..\manifest.json,..\privacy.html www\
Copy-Item ..\icons\*.png www\icons\
npx cap sync android
python make_android_icons.py      # launcher icons + splash
cd android
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-25.0.3.9-hotspot"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat :app:bundleRelease
```

The AAB is unsigned. Sign it with jarsigner and the Parker Data Link upload key (same key as the Browser and Simple VPN), then upload to Play.

## Deploy the web version

```powershell
Copy-Item index.html,manifest.json,privacy.html,serviceworker.js,ads.txt,app-ads.txt web\
Copy-Item icons web\ -Recurse -Force
npx wrangler pages deploy web --project-name skyhop --branch main
```
